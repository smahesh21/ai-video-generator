## Current limitations

- The studio's account mode queues fixture renders in MongoDB, and a separate local worker runs the pipeline. The credential-free mode still launches its older child process. The separate generation-state screen is still a UI simulation; the real job is on the Video render screen. A worker crash triggers one fresh attempt with a new ID after lease expiry; it does not resume partial MP4 work, and a second loss needs creator action. Queued account jobs wait if the worker is offline, and the Video screen now explains worker availability. Account snapshots, stages, terminal status, and completed R2 Ready records are saved in MongoDB. New account-owned MP4s and posters use the private `drishvo-develop` R2 bucket under `drishvo/renders/`. A disposable queued render reached Ready with a 5.46 MB MP4 in R2 and was removed afterward; signed-in browser playback had passed for the earlier account render path, but this new queue/recovery/availability UI has not yet been walked through in the browser. Local video bytes stream from disk, while R2 responses are currently buffered in server memory. A separate production bucket and token are still needed before deployment.
- Account mode is configured locally with MongoDB and one approved internal user. Previous browser drafts remain in local-mode storage and are intentionally not imported into accounts. Switching modes changes which workspace appears. Explicit project deletion removes its approval history.
- The studio storyboard and video concept are illustrative. AI brainstorming, AI script/storyboard generation, and live voiceover are not yet available through the UI. The new render output is a silent test MP4 with simplified supported graphics.
- Fixture MP4s have silent synthetic narration timing and topic-matched schematic animation for the supported motifs. They are real files, but they do not yet deliver custom AI-generated visual assets, ElevenLabs voice quality, or voice-to-motion synchronization described in the product goal. Local illustrative storyboards may still contain generic educational copy.
- The ignored `apps/studio/.env.current-login` file holds the latest locally issued sign-in details; the prior bootstrap credential file was removed. Signed-in users can change their password under Account. Forgotten-password email recovery is not yet available.
- Publish review can save a caption in the current workspace and show Instagram account-status examples, but no Instagram authorization, posting, scheduling, durable job/media storage, or billing is live.
